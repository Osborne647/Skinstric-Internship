AI-powered skincare quiz that captures a selfie via camera or gallery upload, analyzes it through a machine learning API, and returns demographic predictions with confidence scores. Includes a live weather/environmental factors dashboard tailored to the user's location.

**Tech:** Next.js 16, React 19, TypeScript, Tailwind CSS, Vercel
